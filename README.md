# BioLoom project website

This repository contains the static site for **Scaling Biomedical Vision-Language Models by Learning from the Structure of Scientific Articles**. Open `index.html` in a browser to preview the interactive method figure, retrieval animation and paper results. The page runs without a build step.

The retrieval demo uses a shared gallery of 1,000 figures, with 800 from BioLoomBench and 200 from BioMedFlickr. The demo shows 15 concise-caption and 15 original-caption BioLoomBench queries, plus 15 BioMedFlickr queries with benchmark captions. BioLoom ranks the exact paired figure first in every case. The menu identifies cases where one baseline also ranks it first.
